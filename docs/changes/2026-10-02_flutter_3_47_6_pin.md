# Flutter 3.47.6 toolchain pin

Bump repo Flutter pin from `3.47.5` → `3.47.6` and Dart from `3.13.4` → `3.13.5`.

## Why

Local/SDK stable is already 3.47.6 (Dart 3.13.5) after `flutter upgrade`; CI/docs/README
badges still said 3.47.5 / 3.13.4.

## How

```bash
python3 tool/update_agent_toolchain_versions.py --from-sdk
flutter pub get
```

Synced sinks: `docs/toolchain_versions.env`, README badges, [`tech_stack.md`](../tech_stack.md),
CI workflows (`ci`, `drift`, `deploy_web`, `mobile_release_dry_run`), Melos baseline
header. `pubspec.lock` unchanged on this SDK bump.
