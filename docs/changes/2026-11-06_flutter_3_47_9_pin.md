# Flutter 3.47.9 toolchain pin

Bump repo Flutter pin from `3.47.7` → `3.47.9` and Dart from `3.13.5` →
`3.13.7`.

## Why

Local/SDK stable is already 3.47.9 (Dart 3.13.7) after `flutter upgrade`;
CI/docs/README badges still said 3.47.7 / 3.13.5. Needed for #1083 validation
on Lacie.

## How

```bash
python3 tool/update_agent_toolchain_versions.py --from-sdk
flutter pub get
```

Synced sinks: `docs/toolchain_versions.env`, README badges, [`tech_stack.md`](../tech_stack.md),
CI workflows (`ci`, `drift`, `deploy_web`, `mobile_release_dry_run`), Melos baseline
header. Living FAQ / new-developer-guide pins updated.

## Verification

- `python3 tool/update_agent_toolchain_versions.py --check`
- `flutter --version` → Flutter 3.47.9 / Dart 3.13.7
