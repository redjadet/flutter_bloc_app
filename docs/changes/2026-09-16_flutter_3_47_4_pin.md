# Flutter 3.47.4 toolchain pin

Bump repo Flutter pin from `3.47.3` → `3.47.4`. Dart stays `3.13.3`.

## Why

Local/SDK stable is already 3.47.4 (Dart 3.13.3) after `flutter upgrade`; CI/docs/README
badges still said 3.47.3.

## How

```bash
python3 tool/update_agent_toolchain_versions.py --from-sdk
flutter pub get
```

Synced sinks: `docs/toolchain_versions.env`, README badges, [`tech_stack.md`](../tech_stack.md),
CI workflows (`ci`, `drift`, `deploy_web`, `mobile_release_dry_run`), Melos baseline
header. `pubspec.lock` refreshed on new SDK.

Analyzer: drop `unawaited(...)` around `showAdaptiveDialog` /
`showModalBottomSheet` (`unnecessary_unawaited`; APIs are `@awaitNotRequired`).

macOS Podfile `post_install` deployment target `10.15` → `12.0` so Xcode 27
accepts CocoaPods targets (`FlutterMacOS`, plugin pods).
