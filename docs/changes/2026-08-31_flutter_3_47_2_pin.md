# Flutter 3.47.2 toolchain pin

Bump repo Flutter pin from `3.47.1` → `3.47.2` and Dart from `3.13.1` → `3.13.2`.

## Why

Local/SDK stable is already 3.47.2 (Dart 3.13.2) after `flutter upgrade`; CI/docs/README
badges still said 3.47.1 / 3.13.1.

## How

```bash
python3 tool/update_agent_toolchain_versions.py --from-sdk
flutter pub get
```

Synced sinks: `docs/toolchain_versions.env`, README badges, `docs/tech_stack.md`,
CI workflows (`ci`, `dependency-updates`, `drift`, `deploy_web`,
`mobile_release_dry_run`), Melos baseline header. `pubspec.lock` refreshed on new SDK.

## Verification

- `python3 tool/update_agent_toolchain_versions.py --check`
- `python3 -m unittest tool.update_agent_toolchain_versions_test`
- `./bin/integration_tests` green on supported platforms
