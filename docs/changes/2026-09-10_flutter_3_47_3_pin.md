# Flutter 3.47.3 toolchain pin

Bump repo Flutter pin from `3.47.2` → `3.47.3` and Dart from `3.13.2` → `3.13.3`.

## Why

Local/SDK stable is already 3.47.3 (Dart 3.13.3) after `flutter upgrade`; CI/docs/README
badges still said 3.47.2 / 3.13.2.

## How

```bash
python3 tool/update_agent_toolchain_versions.py --from-sdk
flutter pub get
```

Synced sinks: `docs/toolchain_versions.env`, README badges, [`tech_stack.md`](../tech_stack.md),
CI workflows (`ci`, `drift`, `deploy_web`, `mobile_release_dry_run`), Melos baseline
header. `pubspec.lock` refreshed on new SDK.

## Verification

- `python3 tool/update_agent_toolchain_versions.py --check`
- `python3 -m unittest tool.update_agent_toolchain_versions_test`
- `bash tool/check_docs_gardening.sh`
- `./tool/analyze.sh` (mobile + mix_lint + file_length)
- `dart run melos run analyze` (workspace packages)
- `cd apps/mobile && flutter test` (unit/widget suite)
