# Flutter 3.44.9 toolchain pin

Bump repo Flutter pin from `3.44.8` → `3.44.9` (Dart stays `3.12.2`).

## Why

Local/SDK stable is already 3.44.9 after `flutter upgrade`; CI/docs/README
badges still said 3.44.8.

## How

```bash
python3 tool/update_agent_toolchain_versions.py --from-sdk
```

Synced sinks: `docs/toolchain_versions.env`, README badges, `docs/tech_stack.md`,
CI workflows (`ci`, `dependency-updates`, `drift`, `deploy_web`,
`mobile_release_dry_run`), Melos baseline header.

Also added `mobile_release_dry_run.yml` to `WORKFLOW_FLUTTER_SINKS` so future
pin bumps cannot leave that workflow behind.

## Verification

- `python3 tool/update_agent_toolchain_versions.py --check`
- `python3 -m unittest tool.update_agent_toolchain_versions_test`
- Prior lane: `./bin/integration_preflight` + `./bin/integration_tests` green
  on iPhone simulator after the SDK upgrade
