## Problem

Interviewers need one runnable production-ownership walkthrough: consent-gated
analytics, Remote Config kill-switch, safe FCM, Crashlytics status, live frame
metrics, and links to sync/native proof — on a fresh clone without Firebase or
store secrets.

## Scope

- In: `/production-readiness` feature (CA + Cubit), app-level `ProductAnalytics`
  - consent Settings toggle, RC keys `production_demo_*`, FCM simulation +
  redaction, `FrameTimingMonitor`, dry-run workflow, portfolio docs
- Out: Mixpanel/Sentry/Patrol, Firebase Performance, store upload, Firebase
  deploy, new backend service, implying CV years in repo docs
