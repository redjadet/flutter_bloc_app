# Flutter 3.47.0 / Dart 3.13.0 toolchain pin

Bump repo Flutter pin from `3.44.9` → `3.47.0` (Dart `3.12.2` → `3.13.0`).

## Why

Local/SDK stable is already 3.47.0 + Dart 3.13.0 after `flutter upgrade`.
CI/docs/README badges still said 3.44.9 / 3.12.2.

## How

```bash
python3 tool/update_agent_toolchain_versions.py --from-sdk
```

Synced sinks: `docs/toolchain_versions.env`, README badges, [`tech_stack.md`](../tech_stack.md),
CI workflows (`ci`, `dependency-updates`, `drift`, `deploy_web`,
`mobile_release_dry_run`), Melos baseline header.

Also kept first-party `sdk` floors at `>=3.12.0 <4.0.0` (Dart 3.12 language).
Dart 3.13 primary constructors make `final` / `var` on ordinary function
parameters a compile-time error; this repo still uses `final` parameters, so
raising the language floor is a separate migration (`parameter_assignments`
instead of `final` params).

Also raised the macOS deployment target from `10.15` to `12.0` (Flutter 3.47
minimum). Flutter 3.47 dropped `MinimumOSVersion` from
`apps/mobile/ios/Flutter/AppFrameworkInfo.plist` and refreshed the iOS Flutter
pod checksum in `Podfile.lock`.

Did **not** opt into standalone `material_ui` / `cupertino_ui` this release;
SDK-bundled libraries remain until the November deprecation.

Kept Hive web `--wasm` default-off (3.47 still treats Wasm as opt-in).

Dart 3.13 analyzer also flags `unawaited_return_in_try_block`,
`unused_catch_stack`, and `unnecessary_unawaited` (`Navigator.push` /
`AnimationController.forward` are `@awaitNotRequired`). Tuned those call
sites so `./tool/analyze.sh` is clean.
